# Import semantic-net nodes

These instructions accompany the nine-column CSV files generated on 2026-09-14.
Verified in an isolated Neo4j 5.26.30 / APOC Core 5.26.30 instance, using local
copies of the six CSVs. Initial import, reruns and optional-property refresh passed.
Use a separate empty database for this schema revision. The scripts do not migrate
legacy nodes identified by `id`, or remove nodes deleted from a CSV.

Run order: **README_nodes.md -> README_relationships.md -> README_index.md**.
Run each Cypher block separately. Target: Neo4j 5.26 with matching APOC Core.
The GitHub URLs require the new CSVs to be uploaded first. For local import, put
the six files in Neo4j's import directory and replace each URL with
`file:///material_data.csv`, etc. File names are case-sensitive.

## 0. Prerequisites and constraints

Check the installed versions:

```cypher
CALL dbms.components() YIELD name, versions
RETURN name, versions;
```

```cypher
RETURN apoc.version() AS apoc_version,
       apoc.convert.fromJsonList('[1.0,2.0]') AS parsed_list;
```

Stop if legacy category nodes are present. Use the separate empty database rather
than combining the old and new schemas.

```cypher
MATCH (n)
WHERE (n:Material OR n:Usage OR n:Stimulus OR n:Stimuli
       OR n:Response OR n:Transformation OR n:Behavior)
  AND n.node_id IS NULL
WITH count(n) AS legacy_count
CALL apoc.util.validate(
  legacy_count > 0,
  'Found %d legacy nodes. Use a separate empty database.',
  [legacy_count]
)
RETURN legacy_count;
```

```cypher
CREATE CONSTRAINT semantic_node_id IF NOT EXISTS
FOR (n:Embeddable) REQUIRE n.node_id IS UNIQUE;
```

```cypher
CREATE CONSTRAINT semantic_node_slot IF NOT EXISTS
FOR (n:Embeddable)
REQUIRE (n.source_index, n.perspective_type, n.category) IS UNIQUE;
```

## Field mapping and reruns

| CSV field | Node property / purpose |
| --- | --- |
| node_id | Globally unique identity, for example M-PD-01 |
| source_index | Integer source group, currently 1-10 |
| perspective_type | PD, PE or MS |
| category | Singular category label |
| name | Perspective-specific concept name |
| description | Perspective-specific description |
| parameter_text | Optional existing parameter text |
| embedding | Parsed 384-dimensional numeric list |
| parameter_embedding | Optional parsed 384-dimensional numeric list |

Each category retains the original PD / PE / MS `FOREACH` structure.
`MERGE` matches the globally unique `node_id`; `SET` assigns the category and
perspective labels and refreshes the properties on reruns. Empty optional cells
remove those properties. Editing name/description or parameter_text requires
regenerating the corresponding embedding before import.

Vectors are loaded from the CSVs, not generated by these Cypher scripts. All
current node vectors use name + newline + description; optional parameter vectors
use parameter_text. The model is sentence-transformers/all-MiniLM-L6-v2.

## 1. Material nodes

```cypher
LOAD CSV WITH HEADERS
FROM 'https://raw.githubusercontent.com/TinybutGiant/semanticModeling4DP/main/data/material_data.csv' AS row
WITH row,
     toInteger(row.source_index) AS source_index,
     CASE WHEN trim(coalesce(row.embedding, '')) = '' THEN []
          ELSE toFloatList(apoc.convert.fromJsonList(row.embedding))
     END AS embedding,
     CASE WHEN trim(coalesce(row.parameter_text, '')) = '' THEN null
          ELSE row.parameter_text
     END AS parameter_text,
     CASE WHEN trim(coalesce(row.parameter_embedding, '')) = '' THEN null
          ELSE toFloatList(apoc.convert.fromJsonList(row.parameter_embedding))
     END AS parameter_embedding
CALL apoc.util.validate(
  coalesce(row.category, '') <> 'Material'
  OR NOT coalesce(row.perspective_type, '') IN ['PD', 'PE', 'MS']
  OR source_index IS NULL OR source_index < 1
  OR coalesce(row.node_id, '') <> 'M-' + row.perspective_type + '-'
     + CASE WHEN source_index < 10 THEN '0' ELSE '' END + toString(source_index)
  OR trim(coalesce(row.name, '')) = ''
  OR trim(coalesce(row.description, '')) = '',
  'Invalid Material identity or text: %s', [coalesce(row.node_id, '(missing)')]
)
CALL apoc.util.validate(
  size(embedding) <> 384
  OR any(value IN embedding WHERE value IS NULL)
  OR reduce(norm = 0.0, value IN embedding | norm + value * value) <= 0.0,
  'Invalid embedding: %s', [row.node_id]
)
CALL apoc.util.validate(
  (parameter_text IS NULL AND parameter_embedding IS NOT NULL)
  OR (parameter_text IS NOT NULL AND parameter_embedding IS NULL)
  OR (parameter_embedding IS NOT NULL AND
      (size(parameter_embedding) <> 384
       OR any(value IN parameter_embedding WHERE value IS NULL)
       OR reduce(norm = 0.0, value IN parameter_embedding | norm + value * value) <= 0.0)),
  'Invalid parameter text/vector pairing: %s', [row.node_id]
)

// For PD perspective
FOREACH (ignoreMe IN CASE WHEN row.perspective_type = 'PD' THEN [1] ELSE [] END |
    MERGE (n:Embeddable {node_id: row.node_id})
    SET n:Material:PD_Material,
        n.source_index = source_index,
        n.perspective_type = row.perspective_type,
        n.category = row.category,
        n.name = row.name,
        n.description = row.description,
        n.parameter_text = parameter_text,
        n.embedding = embedding,
        n.parameter_embedding = parameter_embedding
)

// For PE perspective
FOREACH (ignoreMe IN CASE WHEN row.perspective_type = 'PE' THEN [1] ELSE [] END |
    MERGE (n:Embeddable {node_id: row.node_id})
    SET n:Material:PE_Material,
        n.source_index = source_index,
        n.perspective_type = row.perspective_type,
        n.category = row.category,
        n.name = row.name,
        n.description = row.description,
        n.parameter_text = parameter_text,
        n.embedding = embedding,
        n.parameter_embedding = parameter_embedding
)

// For MS perspective
FOREACH (ignoreMe IN CASE WHEN row.perspective_type = 'MS' THEN [1] ELSE [] END |
    MERGE (n:Embeddable {node_id: row.node_id})
    SET n:Material:MS_Material,
        n.source_index = source_index,
        n.perspective_type = row.perspective_type,
        n.category = row.category,
        n.name = row.name,
        n.description = row.description,
        n.parameter_text = parameter_text,
        n.embedding = embedding,
        n.parameter_embedding = parameter_embedding
)
RETURN count(*) AS imported_rows;
```

Expected for the supplied CSV: 30 imported rows (including matched rows on rerun).

## 7. Check the imported nodes

```cypher
MATCH (n:Embeddable)
RETURN n.category AS category, n.perspective_type AS perspective,
       count(*) AS nodes, count(n.embedding) AS node_vectors,
       count(n.parameter_text) AS parameter_texts,
       count(n.parameter_embedding) AS parameter_vectors
ORDER BY category, perspective;
```

Expected: 18 groups with 10 nodes each, 180 node vectors and 10 parameter
vectors overall. Parameter vectors currently belong to Material / MS only,
but the schema supports them in any category and perspective.

MATCH (n:Embeddable)
